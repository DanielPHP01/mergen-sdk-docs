    Кастомизация вида¶

    Внешний вид встроенного оверлея полностью описывает ScannerStyle — единый набор полей на обеих платформах (Android: размеры в dp/sp, цвета ARGB Int; iOS: CGFloat и Color). Стиль принимают MergenScannerView (Compose / SwiftUI / XML / UIKit); у MergenScanView самые ходовые параметры (bboxColor, bboxStyle, strokeWidth/cornerLength, showGuideFrame, отступ прогресса) вынесены прямо в сигнатуру.

    Если стилизации не хватает — рисуйте оверлей полностью сами: см. «Свой UI поверх сканера».

    Сборка стиля¶

    let style = ScannerStyle {
    $0.bboxDrawStyle = .cornersOnly
    $0.colorSuccess  = Color(red: 0, green: 0.88, blue: 0.46)
    $0.strokeWidth   = 4
    $0.hintPositionFraction = 0.15
}
// Пресеты: ScannerStyle.minimal (тонкие уголки), ScannerStyle.bold (толстая рамка)

    // Kotlin DSL
val style = ScannerStyle.build {
    bboxDrawStyle        = BBoxDrawStyle.CORNERS_ONLY
    colorSuccess         = Color.parseColor("#00E676")
    strokeWidthDp        = 4f
    hintPositionFraction = 0.15f
}
// Пресеты: ScannerStyle.minimal(), ScannerStyle.bold()

// Java-friendly Builder (покрывает основные поля; расширенные —
// hintCornerRadiusDp, hintPositionFraction, progressTrackColor,
// progressHeightDp, progressCornerRadiusDp, showAnalyzeAnimation —
// доступны только через DSL или copy())
val style2 = ScannerStyle.Builder()
    .bboxDrawStyle(BBoxDrawStyle.CORNERS_ONLY)
    .colorSuccess(Color.GREEN)
    .build()

    Стиль рамки — BBoxDrawStyle¶

    Значение Вид
    cornersAndRect / CORNERS_AND_RECT полный прямоугольник с усиленными угловыми акцентами (по умолчанию в ScannerStyle)
    cornersOnly / CORNERS_ONLY только четыре Г-образных угловых скобки (по умолчанию в MergenScanView)
    fullRect / FULL_RECT простой скруглённый прямоугольник
    none / NONE рамка не рисуется — для полностью своего оверлея

    Все поля ScannerStyle¶

    Значения по умолчанию едины для обеих платформ (в скобках — имя на Android, если отличается).

    Рамка карты¶

    Поле Дефолт Что делает
    bboxDrawStyle cornersAndRect стиль рамки (см. выше)
    strokeWidth (strokeWidthDp) 3 толщина линий
    cornerLength (cornerLengthDp) 28 длина плеча угловой скобки
    cornerRadius (cornerRadiusDp) 12 скругление углов
    bboxPaddingFraction 0.04 дополнительный отступ вокруг детектированной карты, в долях меньшей стороны

    Цвета состояний рамки¶

    Поле Дефолт Когда применяется
    colorIdle белый карта не обнаружена
    colorDetecting жёлтый карта в кадре, идёт стабилизация (им же красится анимация сканирующей линии)
    colorSuccess #00E075 успешный захват
    colorFailure красный ошибка, отклонение side-gate, несовпадение стороны

    Затемнение и подсказки¶

    Поле Дефолт Что делает
    dimColor чёрный 35% полноэкранное затемнение вокруг рамки
    hintTextSize (hintTextSizeSp) 15 размер текста подсказки
    titleTextSize (titleTextSizeSp) 18 размер заголовка статуса
    hintTextColor / titleTextColor белый цвета текста
    hintBackgroundColor чёрный 72% плашка под текстом
    hintCornerRadius (hintCornerRadiusDp) 10 скругление плашки
    hintPositionFraction 0.12 позиция блока подсказки — доля высоты от нижнего края

    Прогресс¶

    Поле Дефолт Что делает
    showProgressBar false линейный прогресс-бар (по умолчанию его роль играет анимация сканирующей линии)
    progressColor #00E075 заливка
    progressTrackColor белый 25% трек
    progressHeight (progressHeightDp) 4 высота
    progressCornerRadius (progressCornerRadiusDp) 2 скругление
    progressBottomInset (progressBottomOffsetDp) 0 / 92 отступ полосы от нижнего края (Android-дефолт 92dp оставляет место под кнопку)

    Дополнительно¶

    Поле Дефолт Что делает
    showAnalyzeAnimation true анимация сканирующей линии внутри рамки в фазе анализа
    showGuideFrame false статичная направляющая рамка ID-1 по центру + гейт: захват принимается, только когда карта перекрывает рамку ≥ 80 % площади
    showConfidenceLabel false отладочная метка уверенности детекции
    showDebugInfo false зарезервировано

    Направляющая рамка

    showGuideFrame = true — самый простой способ получить сценарий «положите карту в рамку»: SDK сам рисует рамку пропорций ID-1, затемняет область вне её и не завершает захват, пока карта не внутри. Состояние «карта в рамке» доступно и вашему коду — ScannerFrameState.isCardInGuide / cardInGuide.
